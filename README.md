# Soya Tab Group Workspace

**把 Chrome 已打开的网页放到一张总览里，方便你找网页、整理分组、关闭重复页面。**

## 不懂代码，先从这里开始

这是给电脑上的 Chrome 浏览器加一个小工具，不需要写代码。请先用几个不重要的网页试用。

1. 在本页上方点击绿色 **Code** 按钮，再点 **Download ZIP**（下载压缩包）。
2. 在电脑的“下载”文件夹找到压缩包，双击解压。不要删除解压出的文件夹，浏览器之后还要读取它。
3. 在 Chrome 顶部地址栏输入 `chrome://extensions` 并回车，打开右上角“开发者模式”。这里是 Chrome 安装本地小工具的入口，不要求你会编程。
4. 点击“加载已解压的扩展程序”，选择 解压后文件夹里的 `extension` 文件夹。选中的是文件夹，不是里面某个文件。
5. 新开一个 Chrome 标签页。先只整理几个测试网页，不要第一次就点“关闭整个分组”。

**第一次成功的样子：** 你应看到已打开网页和分组的总览，能点开某个网页。

找不到文件夹：检查是否已经解压、是否多套了一层同名文件夹。看不到效果：确认扩展开关已开启，再刷新测试网页。仍不成功时，先关闭这个扩展开关；它不会因此把旧版本自动恢复。卸载前阅读后面的数据保留说明。

不需要付费账号。它会读取已打开网页的标题、地址和分组，在你的电脑上整理。关闭网页可能丢失尚未提交的文字；先保存内容，误关后可尝试 Chrome 的“重新打开关闭的标签页”。

后面的配置和代码说明可跳过。“Issues”是本页上方的公开提问区，提问前请删去私人和工作信息。



浏览器里开着几十个标签页时，它们通常都代表一件还没处理完的事。一份要读的材料、一个要核对的数据页面、一篇准备学习的文章，暂时关不掉，于是越积越多。

你可能已经用 Chrome 标签组把工作、学习和不同项目分开。问题是，标签组只能整理当前窗口，网页一多以后仍然很难看清全貌。同一个页面可能开了两三份，临时网页忘了归类，学习资料放了几周也没有真正读完。

Tab Group Workspace 会把 Chrome 的新标签页换成一张总览。它直接沿用你已有的标签组、名称和颜色，让你在一个页面里看清所有网页，然后完成清重、移动、刷新和关闭。你不用再维护另一套分类。

## 它适合谁

- 平时会同时打开几十个网页，并且已经在使用 Chrome 标签组。
- 把网页当作临时待办，希望处理完以后顺手关闭。
- 同时推进多个项目，需要快速看清每个分组里还留着什么。
- 经常积累研究、课程、AI 工具和文章，希望减少“先放着以后看”。
- 希望数据看板或后台页面能够按组一键刷新。

## 它解决什么问题

### 看清全部网页

工作台按 Chrome 原生分组展示所有标签。两列卡片会自动补位，分组数量不同时也不会留下大块空白。

### 清掉重复和闲置页面

重复网页只显示一份，并标出副本数量。点击一次即可保留最近使用的页面，关闭其他副本。当前页、固定页和刚打开的页面不会被低活跃建议误伤。

### 继续使用原来的分类

网页可以直接拖进其他 Chrome 分组。未分组页面支持自动判断和归类，找不到现成目标组时可以创建新组。系统拿不准的页面会继续留在原处。

### 批量处理一个分组

每个分组都可以整组刷新、清理重复页面或关闭。适合数据看板、运营后台以及一批已经处理完的临时网页。

### 给学习页面一个明确出口

AI、课程和研究类网页会得到“优先学习”提示。读完以后可以直接点击“学完关闭”，避免学习资料长期堆在浏览器里。

## 可选的个人化设置

页面标题、头像、主题色、日签开关和自动分类规则都可以修改。日签只显示日期、时间、节气、干支和简单的“宜 / 慎”，不会读取日程、日记或待办。

## 它不适合谁

- 只开少量网页，不使用 Chrome 标签组。
- 需要跨设备云同步、多人协作或正式任务管理。
- 希望扩展自动阅读网页内容并替自己决定业务优先级。
- 需要把标签页长期保存为书签或知识库。

所有数据都保存在 `chrome.storage.local`。扩展没有服务器、账号系统、遥测或外部 API。

## 第一次使用与预期结果

安装后打开新标签页，应看到现有标签组和网页总览。先在临时 Chrome 配置里只放三条非敏感测试网页，确认显示、移动和关闭行为；不要首次就在重要工作窗口执行整组关闭。未分组/重复识别不等于业务重要性判断。

## 安装

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择仓库中的 `extension/` 目录。

## 自定义

复制配置示例。

```bash
cp extension/config.local.example.js extension/config.local.js
```

编辑 `config.local.js`。

```js
globalThis.TAB_WORKSPACE_CONFIG = {
  title: 'My Workspace',
  avatar: 'icons/icon128.png',
  accentColor: '#65786d',
  showAlmanac: true,
  categoryRules: [
    { category: 'Research', hosts: /arxiv|scholar/i, words: /paper|research/i },
  ],
};
```

`config.local.js` 已被 Git 忽略，适合存放个人标题、分类和本地图标路径。不要在其中写入密钥或账号凭据。

## 隐私与权限

扩展使用 `tabs`、`activeTab`、`storage`、`tabGroups`、`idle` 和 `alarms`。

- 读取标签标题、URL、图标和原生分组，用于本地展示与整理。
- 通过用户点击执行关闭、刷新、移动和自动分组。
- 本地记录前台停留与刷新次数，用于低活跃提示；锁屏或空闲时间不计入。
- 不包含服务器、账号、遥测或外部 API 请求。

详见 [PRIVACY.md](PRIVACY.md) 和 [SECURITY.md](SECURITY.md)。
